# Reproducibility Materials

This repository contains the scripts used to reproduce the analyses, figures, and tables reported in the study.

## Data setup

1. Download the dataset from [OneDrive](https://utbcz-my.sharepoint.com/:x:/g/personal/wolde_utb_cz/IQDHsRfhBG84RZSBp9lrbYCeAcCImK338Ey6InZV6lHapwI?e=lI3QgG).
2. Extract the downloaded file.
3. Place the dataset file inside the repository’s folder without changing its filename.
4. Run the analysis scripts in their numbered order from the repository root.

The scripts require the folder structure to be preserved.
